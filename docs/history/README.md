# Historical project documents

These files preserve decisions, measurements, and investigations from the path
to v0.1. They are intentionally not the active queue. Current work is tracked
only in [`ROADMAP.md`](../../ROADMAP.md).

- [`PLAN.md`](PLAN.md) — original product and architecture plan.
- [`FINISH.md`](FINISH.md) — compiler-completion diary and staged engine plan.
- [`BASELINE.md`](BASELINE.md) — original macOS corpus and AI-localization
  baseline.
- [`BENCHMARKS.md`](BENCHMARKS.md) — dated pre-v0.1 engine performance record.
- [`engine-notes/`](engine-notes/) — individual differential-debugging
  investigations.

Numbers here may be obsolete. Use `docs/RELEASE.md` for v0.1 claims and the
active roadmap's versioned performance artifacts for later claims.
