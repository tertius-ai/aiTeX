# aiTeX — Baseline Timings

Numbers to beat. Generated by `tools/bench.py` / `tools/verify_mutants.py`.

**Machine:** TeX Live 2024, pdfTeX 1.40.26, 14 cores / 36 GB, macOS (Darwin 23.1.0).  
**Flags (all runs):** `max_print_line=1000 -file-line-error -interaction=nonstopmode -no-shell-escape`, `SOURCE_DATE_EPOCH` + `FORCE_SOURCE_DATE=1` for reproducible PDFs.  
**Method:** each project copied to scratch, build artifacts stripped; cold = first run, warm = median of runs 2–3.

## Total compile time — clean corpus

Seconds. `latexmk` runs to convergence (multiple passes + bib); `pdflatex` is a single pass.

| Measurement | Median | Mean | Min | Max |
|---|---|---|---|---|
| Local · pdflatex cold | 0.94 | 1.07 | 0.48 | 3.82 |
| Local · pdflatex warm | 0.87 | 0.94 | 0.49 | 2.12 |
| Local · latexmk to convergence | 3.79 | 3.75 | 1.54 | 7.27 |
| arXiv · pdflatex cold | 1.71 | 3.81 | 0.40 | 66.54 |
| arXiv · pdflatex warm | 1.44 | 2.88 | 0.39 | 20.18 |
| arXiv · latexmk to convergence | 5.84 | 10.96 | 0.99 | 59.50 |

**Headline (all clean projects):**

- single-pass `pdflatex`: **1.21s** median (first run 1.23s)
- `latexmk` to convergence: **4.78s** median
- convergence costs **4.0×** a single pass — the prize for rerun prediction (plan §7)

> **Repeated runs save only 2%.** Re-running `pdflatex` on an unchanged document is nearly as expensive as the first run: it reloads the format, re-reads every package, and re-executes the whole preamble every time. There is no process-level warm path to exploit.
>
> This is a *supporting* result for plan §7 rather than a discouraging one. It says the ~60% preamble-snapshot win cannot come from OS or filesystem caching — pdfTeX already benefits from those here — so it has to come from architecture: snapshotting interpreter state at `\begin{document}` and resuming, which no stock engine does.

## Localization gap distribution

`gap = |reported_line − true_line|`. The whole point of the corpus: log-only parsing degrades as gap grows.

| Bucket | Count | Meaning |
|---|---|---|
| `gap=0` | 241 | pdflatex points exactly at the cause |
| `0<gap<=50` | 333 | near miss — same file, wrong line |
| `gap>50` | 330 | **non-localized** — cause far from report |
| `unlocalizable` | 96 | **no line reported at all** |
| **total** | **1000** | |

**43% of the corpus is non-localized** (gap>50, no line, or wrong file) — where the harness must earn its keep.
