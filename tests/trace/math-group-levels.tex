% `tex.web` §1153: only an explicit `{` in math mode opens a sub-formula.
%
%     mmode+left_brace: begin tail_append(new_noad); back_input;
%       scan_math(nucleus(tail));
%       end;
%
% `scan_math` is what reaches `push_math(math_group)`.  Every other
% `new_save_level` — `\insert`, `\vadjust`, `\begingroup`, a box, `\output` —
% leaves the math list alone, however its body is delimited.
%
% This engine pushed a level for all of them, out of one shared `begin_group`.
% The level was never popped, and §211's name for math turns on exactly that
% count: a display is `display math mode` while its own list is the innermost
% and `math mode` once anything sits above it.  So
%
%     $$\vadjust{\penalty7}\mkern-9mu$$
%
% reported `{math mode: \mkern}` where TeX reports `{display math mode:
% \mkern}` — trip.tex line 262, and every command after it in that display.
%
% The four groups that *do* push are `{` itself, `\left` (§1191), each of
% `\mathchoice`'s four (§1172/§1173), and `scan_math`'s brace form under
% `\mathord` and its fellows (§1151).
